# Хранилище настолок

Склад карт с удобным разбиением на листы для печати. Колоды лежат в коде, на экране — просмотр, на выходе — PDF под гильотину.

Лист по умолчанию SRA3 (320×450 мм). Вылет 3 мм, между линиями реза 6 мм, поле до реза не меньше 12 мм. Метки стоят только во внешнем поле. Оборот зеркалится по длинной стороне.

Сайт: https://pavladog.github.io/card-generator/

## Локально

```bash
npm install
npm run dev
```

`npm test` проверяет сетку. `npm run check` проверяет, что колоды заполнены и картинки лежат в `public`.

## Новая колода или дизайн

Дизайны лежат в `src/designs/<id>/design.ts`: размер, вылет, поля и функция отрисовки в миллиметрах. Колода — `deck.ts` рядом и запись в `src/designs/index.ts`. Картинки кладутся в `public/assets/...`. После правки имеет смысл прогнать `npm run check`.
